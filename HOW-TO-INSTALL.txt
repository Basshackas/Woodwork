TADESSE FURNITURE - installable app (PWA)

1. Put ALL files in this folder on a free HTTPS web host, for example:
   - Netlify Drop: open app.netlify.com/drop and drag this whole folder in
   - or GitHub Pages / Cloudflare Pages
   The host gives you a web link that starts with https://
2. On the phone, open that link in Chrome.
3. Tap the Install app button on the first screen (or the three-dot menu, then Install app / Add to Home screen).
4. Enter the install code from the owner, then create a PIN for that phone.

Notes
- The app and its data are encrypted inside these files. A copy sent by Xender is unreadable without the install code.
- Each phone keeps its own data. Use Settings > Backup now to save a backup to Google Drive or email, and Restore from file on another phone.
- Keep the install code secret. Never put it in this folder.
